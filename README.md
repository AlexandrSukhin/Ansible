# Nginx Docker Deployment with Ansible

Этот проект автоматизирует развёртывание Docker‑контейнера с Nginx с помощью Ansible. Конфигурационный файл Nginx и HTML‑страница монтируются извне в контейнер.

## Требования

Перед запуском убедитесь, что на управляющей машине (где работает Ansible) установлены:

* **Ansible** (версия 2.9 или выше);
* **SSH‑доступ** к целевым серверам (если не используется `localhost`);
* **Docker** на целевых серверах (будет установлен автоматически через playbook, но требуется поддержка ядра);
* **Python 3** на целевых серверах.

## Структура проекта

nginx-playbook/
├── playbook.yml # Основной Ansible playbook
├── files/
│ ├── nginx.conf # Конфигурация Nginx
│ └── index.html # HTML‑страница для публикации
├── inventory # Файл инвентаря (хосты для развёртывания)
└── README.md # Эта документация


## Настройка инвентаря

1. Скопируйте один из шаблонов файла `inventory` из раздела документации (или создайте свой).
2. Настройте параметры под вашу инфраструктуру:
   * IP‑адреса серверов;
   * имена пользователей для SSH;
   * пути к SSH‑ключам (или пароли).

Примеры конфигураций инвентаря см. в документации проекта.
